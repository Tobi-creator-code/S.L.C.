Fonts used by this site (served from this folder, nothing is loaded from the internet)

Poppins (poppins-regular.woff, poppins-medium.woff, poppins-bold.woff)
  Used for headings, buttons and numbers.
  Copyright The Poppins Project Authors. Licensed under the SIL Open Font License 1.1
  (https://openfontlicense.org), which allows you to use and bundle it freely.

Body text uses the font already installed on each visitor's phone or computer
(Segoe UI, Roboto, San Francisco and so on), so it needs no download.

To use a different font: put its .woff2 or .woff files in this folder, change the three
@font-face lines at the top of css/style.css, and change --font-display / --font-body in :root.
